## ✦ Overview

A fully handcrafted personal portfolio for **MD. Mostafa Raihan**, a Network & Support Specialist from Feni, Bangladesh. Built with pure HTML, CSS, and JavaScript — no frameworks, no dependencies — just clean, fast, and performant web code.

The design follows a **dark editorial aesthetic** with brand lime (`#d4ff3f`) accents, glassmorphism cards, and smooth micro-animations that deliver a premium first impression.

---

## ⚡ Features

| Feature | Details |
|---|---|
| 🎨 **Design System** | Dark glassmorphism with brand lime `#d4ff3f` token system |
| 🧠 **3D Hero Canvas** | Three.js animated network mesh rendered in real time |
| 📜 **Scroll Spine** | Fixed left-side progress indicator with glowing fill |
| 🃏 **Sticky Project Cards** | Stacked scroll-based case study cards |
| 📬 **Contact Form** | EmailJS-powered form with fallback for blocked CDNs |
| 📱 **Fully Responsive** | Mobile-first design from 320px to 1440px+ |
| ♿ **Accessible** | Skip link, ARIA labels, focus-visible, keyboard nav support |
| 🔍 **SEO Pro** | Structured JSON-LD schema, Open Graph, Twitter Cards, sitemap |
| ⚡ **Performance** | IntersectionObserver animations, eager LCP image, deferred scripts |
| 🔒 **Custom 404** | Branded 404 page with live 3D canvas |

```
HTML5            → Semantic structure & SEO
```

## 🚀 Deployment

This site is deployed on **Cloudflare Pages** with a custom domain:

```
Live URL → https://mostafaraihan.pages.dev
```

To run locally, open `index.html` in any modern browser. No build step required.

```bash
# Clone the repo
git clone https://github.com/md-mostafaraihan/networkingwithraihan.git

# Open locally
start index.html
```
