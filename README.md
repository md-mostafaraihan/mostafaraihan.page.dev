## 👨‍💻 About This Portfolio

A fully handcrafted personal portfolio for **Md. Mostafa Raihan** — a Cisco & CCNA Network Specialist from Feni, Bangladesh. Built with pure HTML, CSS, and JavaScript — no frameworks, no dependencies — just clean, fast, and high-performance web code.

I specialize in **Cisco enterprise routing and switching**, CCNA-level network design, and hands-on lab configurations using Cisco Packet Tracer. Currently working as an **Assistant Faculty** at One Sky Communications Limited, teaching Cisco networking and CCNA lab skills.
